# 글꼴

- `NotoSansKR-Hangul.ttf`: Noto Sans KR 가변 글꼴(굵기 400~700)에서 영문·한글 음절 11,172자·한글 자모·기본 기호만 남긴 것. 원본 google/fonts `ofl/notosanskr`. 라이선스 `OFL-NotoSansKR.txt`.
- `DMMono-Medium.ttf`: DM Mono Medium에서 영문·숫자·기호만 남긴 것. 한글 사이 띄어쓰기가 고정폭으로 벌어지지 않게 공백과 가운뎃점은 빼서 Noto Sans KR 로 그린다. 원본 google/fonts `ofl/dmmono`. 라이선스 `OFL-DMMono.txt`.

두 글꼴 모두 SIL Open Font License 1.1 이며, 줄인 파일은 fonttools 로 만들었다.
